Before you start

Plug the USB-C cable into the ESP32-S3 board itself — not the base. The base's port only supplies power; the board's own port is the one that talks to your computer. After installing, power the unit from the base port so the LED grid lights up (the board's USB port can't supply enough current for the whole panel — that's expected, not a fault).

Install

  1. Connect the ESP32-S3 board to your computer with a USB-C data cable (charge-only cables won't work).
  2. Pick your panel below and press Install.
  3. Choose the serial port in the browser dialog and confirm.
  4. Wait for it to finish, then power the unit from the base and follow the on-screen setup.

What happens on first boot

Installing erases the board completely, so the clock starts as a factory-fresh unit:

You'll seeMeaning
Red → green → blue, 1s eachSelf-test, so you can check every LED works
Scattered confetti sparklesWaiting for setup — join the WordClock-XXXX WiFi network from your phone
Blue snake crawlingJoining your WiFi
Red snake crawlingConnected, syncing the time
Words light upDone — it's telling the time

To reconfigure later (new WiFi, new timezone), hold both buttons for 3 seconds — the panel flashes white and returns to setup.

Manual install (Safari, Firefox, or scripted)

Download wordclock.bin, then with esptool installed (pip install esptool):

esptool --chip esp32s3 --port <YOUR_PORT> erase-flash
esptool --chip esp32s3 --port <YOUR_PORT> write-flash 0x0 wordclock.bin

Port looks like /dev/cu.usbmodem101 on macOS or COM5 on Windows. The image is a full-flash image, so it starts at offset 0x0.

If it doesn't work

ProblemFix
No ports in the dialogUse a data cable, not charge-only. Try the other USB-C port on the board's side, and close the Arduino IDE / any serial monitor holding the port.
“Failed to initialize”Unplug, hold the BOOT button, plug back in, release, then retry.
Installed, but the panel stays darkPower it from the base's USB-C port — the board's own port can't drive the LEDs.
